# FillSpace MVP Website

A sleek, multi-page MVP website for FillSpace inspired by marketplace UX patterns from Airbnb/VRBO.

## Pages

- `index.html` - Home
- `about.html` - About / How it Works
- `browse.html` - Browse Properties

## Quick start (important)

If you open the HTML files directly in a code editor, you will only see source text.
Run a local web server, then open the URL in your browser:

```bash
npm install
npm run dev
```

Then visit:

```text
http://localhost:4173
```

## Design notes

- Font stack includes Airbnb Cereal (`Airbnb Cereal App`) with system fallbacks.
- Brand palette is matched to the deck PDF and centralized in `assets/css/style.css`.
- Lead generation CTAs are included in header, footer, floating action button, and modal forms.
